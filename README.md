# WL-OIDC

WL-OIDC is a self-hosted, white-label OpenID Connect issuer. It provides service-specific roles and login duration, admin-approved signup, email recovery and a versioned skin contract. It supports public clients with Authorization Code and S256 PKCE and optional rotating refresh tokens.
